# โลโก้ลูกค้า — ที่วางไฟล์

วางไฟล์โลโก้ในโฟลเดอร์นี้ ใช้ชื่อไฟล์ตามคอลัมน์ "ชื่อไฟล์" ข้างล่าง

- **นามสกุล**: `.svg` ดีที่สุด (คมทุกขนาด) รองลงมา `.png` พื้นใส
- **พื้นหลัง**: โปร่งใส หรือขาว ก็ได้ เพราะการ์ดเป็นพื้นขาวอยู่แล้ว
- **ขนาด**: ถ้าเป็น PNG ขอด้านสูงอย่างน้อย 200px จะได้ไม่แตกบนจอ Retina
- **ตัดขอบขาวรอบ ๆ ออกให้ชิดตัวโลโก้** ระบบจะจัดระยะห่างให้เอง

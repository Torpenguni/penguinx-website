# PenguinX Website

F&B Ecosystem Builder — official website.

Single-page static HTML site.

## Local Preview

Open `index.html` in browser, or use VS Code "Live Server" extension.

## Deploy

Auto-deployed via Vercel from `main` branch.
Every push to `main` → Vercel rebuilds in ~30 seconds.

## Structure

- `index.html` — Entire site in one file (HTML + CSS, no build step)
